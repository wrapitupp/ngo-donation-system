# Deck screenshots

Drop four PNGs here and rebuild. The build script embeds any file it finds and
falls back to a styled placeholder frame for any it does not.

| Filename | Capture |
|---|---|
| `01-landing.png` | Landing page or campaigns list, showing live campaign data |
| `02-donate.png` | Campaign detail with the donation widget, or the checkout screen |
| `03-verify.png` | A donation receipt or the public `/verify` page with a confirmed proof |
| `04-admin.png` | Administrator dashboard, reviews queue, or disbursements |

Capture from the live site at `changia-hazel.vercel.app`.

Guidance: use a 1440 px wide browser window, hide bookmarks and extensions, and
capture the viewport rather than the full page. Portrait crops suit the frames
better than wide ones. Light theme reads better on a projector than dark.

Recapture after any UI change. Screenshots are the fastest part of this deck to
go stale.
